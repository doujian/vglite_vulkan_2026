# radialGrad.c REPEAT / REFLECT Spread Mode Analysis

> 基于 OpenVG 1.1 规范 §9.1.2.(f) 与本测试用例具体参数，分析 REPEAT 与 REFLECT 模式的理论出图表现。

## 1. 测试用例参数

| 参数 | 值 |
|---|---|
| 画布 | 480×640，白底 `0xFFFFFFFF` |
| Path | 120×120 正方形 (VG_LITE_S8)，经 `matPath = scale(2.0, 2.0)` → **240×240 在画布左上角** |
| radialGradient | `cx = cy = fx = fy = 120, r = 115`（同心圆，焦点在中心） |
| matGrad | identity（焦点 grad-local (120,120) → screen (120,120) = path 几何中心） |
| color_ramp | 5 stops：暗红(0) → 红橙(0.2) → 红粉(0.4) → 红(0.55) → 浅灰(0.95) |
| filter | LINEAR（实际调用值，非声明的 POINT） |
| pre_mult | 1（颜色预乘 alpha） |
| blend | NONE（直接覆盖） |
| fill_rule | EVEN_ODD |

### 1.1 color_ramp 完整定义

| stop | R | G | B | A | 颜色 |
|---|---|---|---|---|---|
| 0.00 | 0.95 | 0.20 | 0.00 | 0.90 | **暗红** (242, 51, 0, 230) |
| 0.20 | 0.85 | 0.30 | 0.20 | 1.00 | 红橙 |
| 0.40 | 0.75 | 0.10 | 0.30 | 1.00 | 红粉 |
| 0.55 | 0.90 | 0.20 | 0.20 | 1.00 | 红 |
| 0.95 | 0.90 | 0.90 | 0.90 | 1.00 | **浅灰** (230, 230, 230, 255) |

注：R 通道始终高位（0.75–0.95），整体偏红色调；从中心暗红渐变到外圈浅灰。

## 2. 空间坐标映射

```
画布: 480×640
┌────────────────────────┐  y=0
│  ┌──────────────┐       │
│  │ path 240×240 │       │
│  │              │       │
│  │     ⊙focal   │       │  ← 焦点 screen (120,120) = path 几何中心
│  │   r=115↻     │       │     r=115 屏幕半径
│  │              │       │
│  └──────────────┘       │
│       (路径外部=白)      │  y=240
│                        │
│       (背景白)          │
└────────────────────────┘  y=640
x=0                  x=480
```

**关键几何事实**：
- 焦点在 path 中心 (120,120)
- 焦点到 path 四个角的距离 = √(120² + 120²) ≈ **170**
- path 角落的 **t = 170 / 115 ≈ 1.48**（**t > 1.0**，r 之外，会触发 spread）

## 3. OpenVG Spread 规范

OpenVG 1.1 §9.1.2.(f) 定义沿 t 轴的 spread：

### 3.1 PAD (FILL = PAD)

- t < 0 → ramp[0]
- t > 1 → ramp[last]
- **视觉**：焦点中心暗红，外圈渐变到浅灰，r 之外**全是浅灰**。

### 3.2 REPEAT

```
t_wrapped = t - floor(t)   // 周期 1，硬接缝
```

- t = 0.0  → ramp[0] 暗红
- t = 0.95 → ramp[4] 浅灰
- t = 1.0  → **跳回 ramp[0] 暗红**（硬接缝！）
- t = 1.48 → 第 2 周期内 t' = 0.48 → 红粉

**视觉特征**：以焦点为圆心，从内向外呈现**多个红→浅灰→红→浅灰的同心环带**，每个环带宽度对应 r = 115 屏幕像素，**环带之间有硬接缝（颜色突变）**。

### 3.3 REFLECT

```
cycle = mod(t, 2)
t_wrapped = (cycle <= 1) ? cycle : (2 - cycle)   // 周期 2，镜像
```

- t = 0.0  → ramp[0] 暗红
- t = 0.95 → ramp[4] 浅灰
- t = 1.0  → 仍 ramp[4] 浅灰（镜像转折点，平滑过渡）
- t = 1.48 → 第 2 半周期内 t' = 2 − 1.48 = 0.52 → 红色
- t = 2.0  → 回到 ramp[0] 暗红

**视觉特征**：以焦点为圆心，从内向外呈现**暗红→浅灰→浅灰→暗红→… 的镜像同心环带**，**环带之间无接缝（颜色平滑过渡）**。

**多个红→灰→红→灰的同心环带**：

| 半径范围（像素） | t 范围 | 颜色 | 说明 |
|---|---|---|---|
| 0 | 0.0 | 暗红 | 焦点 |
| 0 – 115 | 0.0 – 1.0 | 暗红 → 红橙 → 红粉 → 红 → 浅灰 | 第 1 个完整 ramp 周期 |
| **115 处** | **1.0** | **浅灰 → 暗红突变** | **硬接缝（颜色突然跳变）** |
| 115 – 170 | 1.0 – 1.48 | 暗红 → 红粉 | 第 2 周期，被 path 边角截断 |
| 170 处（path 角落） | 1.48 | 红粉 | t' = 0.48 |

**关键识别特征**：r = 115 处有**清晰的环状颜色跳变**（浅灰 → 暗红的锐利分界线）。

**镜像同心环带**：

| 半径范围（像素） | t 范围 | 颜色 | 说明 |
|---|---|---|---|
| 0 | 0.0 | 暗红 | 焦点 |
| 0 – 115 | 0.0 – 1.0 | 暗红 → 红橙 → 浅灰 | 正向 ramp |
| **115 处** | **1.0** | **浅灰 → 浅灰平滑** | **无接缝（镜像转折点）** |
| 115 – 170 | 1.0 – 1.48 | 浅灰 → 红 | 第 2 半周期，反向 ramp，t' = 0.52 |
| 170 处（path 角落） | 1.48 | 红 | t' = 0.52 |

**关键识别特征**：r = 115 处**颜色平滑无跳变**，整体环带更柔和。

## 5. REPEAT vs REFLECT 对比表

| 维度 | REPEAT | REFLECT |
|---|---|---|
| r = 115 处颜色 | **浅灰 → 暗红突变**（硬接缝） | 浅灰 → 浅灰平滑（镜像转折） |
| 环带数 | 多（每周期一个完整 ramp） | 少（两周期合一个镜像对） |
| 环带颜色序列 | 红红灰 红红灰 … | 红灰 灰红 红灰 灰红 … |
| 视觉锐利度 | 高（接缝明显） | 低（柔和过渡） |
| path 边角颜色（t = 1.48） | 第 2 周期 t' = 0.48 → 红粉 | 第 2 半周期 t' = 0.52 → 红 |
| 文件大小 | 大（环带复杂，PNG 压缩率低） | 中（环带柔和，压缩率较高） |

## 6. 实测 PNG 大小验证

| Mode | 实测 PNG 大小 | 推理 |
|---|---|---|
| FILL / PAD (`radialGrad_2.png` / `_3.png`) | 35,568 B | 单一渐变 + 大片浅灰 → 压缩率高 ✅ |
| **REFLECT** (`radialGrad_0.png`) | **45,475 B** | 镜像环带，柔和过渡 → 中等压缩率 ✅ |
| **REPEAT** (`radialGrad_1.png`) | **50,720 B** | 硬接缝 + 多环带 → 压缩率最低 ✅ |

文件大小排序 **PAD < REFLECT < REPEAT**，**符合理论预期**。REPEAT 比 REFLECT 大 5KB（11%），正是硬接缝带来的高频颜色变化。

## 7. 验证清单

视觉检查 4 张 PNG，应观察到：

- [ ] **FILL 与 PAD 出图完全一致**（OpenVG 规范 FILL = PAD）
- [ ] **REPEAT 在 r = 115 处有清晰环状颜色突变**（浅灰 → 暗红的锐利分界线）
- [ ] **REFLECT 在 r = 115 处无明显分界**（颜色平滑过渡）
- [ ] **REPEAT 比 REFLECT 视觉上更"破碎"**（接缝数量多）
- [ ] **path 外部背景为白色**（白底 `0xFFFFFFFF`）
- [ ] **焦点位于 path 几何中心**（屏幕坐标 120,120），不在 path 角落
- [ ] **整体颜色为暗红 → 浅灰**（无蓝色调）
